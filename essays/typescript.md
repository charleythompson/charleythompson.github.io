I began learning TypeScript for a college course. Before learning TypeScript, my programming experience had mostly been with Java, C, and Python. I had never touched JavaScript, so it felt a little strange skipping directly to TypeScript. Because of my prior programming experience, the idea of variables having strict types was something I was already comfortable with. At the same time, TypeScript is different enough to not feel completely natural to me. It feels like I recognize the pieces, but the way they’re arranged feels almost ‘wrong’.

One of the things that consistently trips me up is the way that TypeScript declares variables. In C or Java, I’m used to writing something like `int x = 0`, with the type appearing before the variable name. In TypeScript, the same variable declaration would look like `let x: number = 0`. This isn’t exactly difficult to understand, but it fights against my muscle memory and feels very unnatural to me. I’ve also started developing a bad habit of forgetting to specify the return type of functions. Since TypeScript can infer the return type and doesn’t send an error, I kept getting away with forgetting it while learning.

So far, my impression of TypeScript is that it’s familiar enough for me to understand, but alien enough that I can’t fully rely on my muscle memory. I like having the explicit types because they make it easier for me to catch mistakes, and it’s also what I’m familiar with from my prior programming experience. I think that my current hangups are just from a lack of experience, and that the more I learn and practice with TypeScript, the more comfortable I will feel.
